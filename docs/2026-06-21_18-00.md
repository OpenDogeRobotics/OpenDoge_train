# 修改记录: 2026-06-21 18:00 (V7 工作流优化)

## 诊断

**全量数据复盘** (R1-R6 + Gen 1-5.2, 30+ 次实验):

### Plan V6 的三个致命假设被数据推翻:

1. **"R3 纯净版是稳定基底"** — 错。R3 自身在 step 3700+ 退化 (mean_reward 20→5)
2. **"push_robots 单项可控 (rew>5)"** — 错。R6 push-only 崩溃至 reward -32.78@step5837
3. **"从 R3 checkpoint 恢复 + push 可渐进训练"** — 错。恢复后 600 轮内 reward 从 20 跌到负值

### 退化时间线 (R6 push-only, 当前运行):
```
Step 3600-4000: mean_reward +20~+24 (恢复后快速适应)
Step 4000-4400: mean_reward 剧烈振荡 (-18~+17)
Step 4400-5200: mean_reward 持续负值 (-32~0)
Step 5200-5897: mean_reward -5~-32, smoothness -1.85, tracking_lin 0.46
```

### 退化不是 push/disturb 导致的，而是普遍规律:
- R3 纯净版: step 3000-3500 peak → step 4300+ 退化 (无任何外力)
- R5 push+disturb: 退化加速 (双开)
- R6 push-only: 退化速度介于两者之间
- Gen 5.1/5.2: 历史上同样在 step 4500-5400 后崩溃

### 根因机制:
1. PPO 探索噪声 (entropy=0.003) 在策略收敛后仍持续扰动
2. 策略被推入 reward landscape 的"悬崖区" (一组参数更新导致连锁恶化)
3. Adam 动量将策略拉向错误方向，不可逆
4. 速度追踪和步态稳定性构成零和博弈，策略晚期选择"暴力追踪"牺牲稳定性

## 修改内容

| 参数 | 旧值 | 新值 | 原因 |
|------|------|------|------|
| `entropy_coef` | 0.003 | 0.002 | Goldilocks: 0.001太低保peak(R4), 0.003仍有late-stage噪声 |
| `push_robots` | True | False | R6证明单项也崩溃，纯净训练关闭所有外力 |
| `disturbance` | False | False | 保持关闭 (R5证明双开更差) |
| `max_iterations` | 6000 | 4000 | 不训练到退化区，在peak区间精确导出 |
| `save_interval` | 300 | 200 | 更密集保存，精确选择最优checkpoint |
| `training_mode` | resume from R3 | fresh from scratch | 不再从退化中的checkpoint恢复 |

## 预期效果

- 纯净训练在 step 2500-3500 达到 peak (mean_reward 20+, smoothness > -0.3, tracking_lin > 0.85)
- noise_std 全程 < 0.23 且趋势平稳(不持续上升)
- 在 step 4000 前导出最优 ONNX
- 鲁棒性通过独立训练获得 (低LR + 弱推力课程)

## 关键设计原则变更

```
V6 (错误):  纯净→resume+push→resume+push+disturb (渐进叠加)
V7 (正确):  纯净训练→peak导出   鲁棒训练(独立)→peak导出
             ↑ 两条独立训练线，互不污染 ↑
```
