# 修改记录: 2026-06-21 14:25

## 诊断

**第二轮分析**: 固定 LR (schedule='fixed') 有效延缓但未根治退化。

对比当前 run (fixed LR) vs 原始 (adaptive LR):
- 当前: peak 16.6@3300 → -9.7@4600 (退化 26.3，速度较慢)
- 原始: peak 14.8@3300 → -15.8@4800 (退化 30.6，速度较快)

**固定 LR 只是退化加速器，不是根因。** 真正原因：

1. `randomize_kp` + `randomize_kd` 仍在开启 — 同一 action 在不同 PD 参数下产生不同 torque，策略无法学会精确控制。这是最破坏性的随机化。
2. `base_height` 惩罚太弱 (-1.5) — 策略学习到"蹲伏省力"是跨参数最优解，形成 Mode 3 (Sitting)。
3. `noise_std` 持续上升 (0.219→0.268) — 策略越来越不自信，PPO 更新相互矛盾。

## 修改内容

| 参数 | 旧值 | 新值 | 原因 |
|------|------|------|------|
| `randomize_kp` | True | False | 改变 action→torque 映射，破坏精确控制学习 |
| `randomize_kd` | True | False | 同上 |
| `base_height` | -1.5 | -3.0 | 2x增强，对抗蹲伏策略 |

**保留开启**: randomize_friction, randomize_motor_strength, randomize_base_mass（物理参数随机化，不改变控制映射）

**保持**: schedule='fixed', disturbance=False, push_robots=False, lr=5e-4, max_iterations=4000

## 预期效果

- 消除 action→torque 的不确定性后，策略应能学到更精确的运动控制
- base_height 惩罚加倍应阻止蹲伏趋势
- noise_std 应收敛而非发散
- 应在 300-500 轮内超越前次 peak (mean_reward 16.6)
